# tgsend

`tgsend` — консольная утилита на C, которая читает данные из `stdin` или из файла и отправляет их в указанный чат Telegram через бота.

---

## Использование

### Начало работы

Создайте бота с помощью [@BotFather](https://t.me/BotFather)

Укажите в конфигурационном файле (`/etc/telegram_sender/sender.conf`) токен вашего бота:

```conf
token=1234567890:ABCDEFGHJKLMNOPQRSTUVWXYZ1234567890
```

Создайте БД для утилиты:

> [!NOTE]
> Если утилита была установлена как `.deb` пакет, этот шаг можно пропустить

```bash
tgsend --create-db
```

#### Добавление нового пользователя

Для добавления пользователя необходимо запустить утилиту с параметром `-a` или `--add-user`

```bash
tgsend -a
```

Данная команда сгенерирует случайный ключ, который нужно отправить в диалог с ботом, после чего, в случае успеха, имя и User ID пользователя будут сохранены для дальнейшего использования.

### Описание функций

|     Опция     | Краткая опция  |                            Описание                                        |
|---------------|----------------|----------------------------------------------------------------------------|
| --add-user    |       -a       | Добавить пользователя в БД (база данных должна существовать)               |
| --create-db   |                | Создать базу данных пользователей или перезаписать существующую            |
| --delete-user |                | Удалить пользователя из БД                                                 |
| --default     |       -d       | Отправка сообщения пользователю по умолчанию (файла или `stdin`)           |
| --file        |       -f       | Указать файл для отправки                                                  |
| --help        |       -h       | Вывести справку                                                            |
| --user_id     |       -i       | Отправка данных по Telegram-ID пользователя (пользователь должен быть в БД)|
| --list-users  |       -l       | Вывести список всех пользователей                                          |
| --set-default |                | Задать пользователя по умолчанию                                           |
| --user        |       -u       | Отправка по имени пользователя (поле First Name в таблице)                 |
| --version     |       -v       | Посмотреть версию ПО                                                       |

### Примеры

Вывести справку:

```bash
tgsend -h
```

Отправка файла:

```bash
tgsend -f file-preview.md
```

Отправка `stdin` пользователю по умолчанию:

```bash
echo "Hello" | tgsend -d
```

## Установка

### Готовые пакеты

#### `.deb` пакет

Скачайте `.deb` из Releases и установите его:

`sudo dpkg -i tg-send_1.0.0_amd64.deb`

#### Другие Linux дистрибутивы

Скачайте бинарный файл из Releases, затем сделайте его исполняемым:

```bash
chmod +x tgsend && sudo mv tgsend /usr/local/bin/
```

Создайте необходимые директории и файлы:

```bash
sudo mkdir -p /var/lib/telegram_sender/
sudo mkdir -p /etc/telegram_sender/
sudo chmod -R 777 /var/lib/telegram_sender/
sudo touch /etc/telegram_sender/sender.conf
sudo chmod -R 755 /etc/telegram_sender/
```

Укажите токен бота:

```bash
echo "token=<token>" | sudo tee /etc/telegram_sender/sender.conf # Токен должен быть указан без пробелов
```

Создайте БД:

```bash
tgsend --create-db
```

### Сборка из исходников (через CMake)

Разработка и сборка производятся в dev-контейнере (см. `.devcontainer` и `Dockerfile`)
